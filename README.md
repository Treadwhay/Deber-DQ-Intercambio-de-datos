# Tarea 4: Intercambio de Datos - API RESTful

Servicio web desarrollado en Java con Spring Boot para gestionar operaciones CRUD de productos mediante formato JSON y pruebas HTTP en Postman.

## Endpoints disponibles
- `POST /api/productos` - Crear un nuevo producto
- `GET /api/productos` - Obtener la lista completa de productos
- `PUT /api/productos/{id}` - Actualizar un producto existente
- `DELETE /api/productos/{id}` - Eliminar un producto por ID
